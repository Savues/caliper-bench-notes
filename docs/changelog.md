## 关于榜单的两种口径

`rank` 字段是按 `cw_score_v3` 排序的名次，不是综合分名次。前几期分析中曾把 rank 当作综合排名引用，导致"综合 32.9 的模型排第 3"这类误读。本仓库的脚本一律按字段值排序，不读 rank。
