基于 **2026-11-21 快照（912 个模型，≤40B 开源 641 个）**。所有表格可用 `scripts/rank.py` 复现。

选型口径分两类，不要混用：

- **要 NSFW / 暗黑** → 看 `erp_score_v3`（露骨能力）和 `drp_score_v3`（暗黑能力），二者都是 0–100 越高越强

`nsfw_v3` 是投递比不是分数，不参与判断，见 [字段说明](字段说明.md)。

## 迭代非单调现象

同一作者的版本号升高，分数经常下降：

```
Glistening-Gem 31B   v2.0 68.7 → v2.1 68.8 → v2.2 67.8
Kitchoon 26B-A4B     v3.1 66.9 → v4 55.4 → v5 60.0 → v5.1 56.7
Artemis 31B          v1.1 64.9 → v1.2 61.2 → v1.2 Heretic 45.6
```

不要默认新版本更好，每次都要看数。
